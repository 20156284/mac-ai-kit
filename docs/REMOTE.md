# 配置 Remotion 远程渲染（可选 Remote 模块）

这是六组件之外的额外配置选项，不加入 `all`。工具包只准备环境和配置，不启动 Remote、Studio、推理或渲染，不安装登录自启动。

## 工具包入口

- 主菜单：`bash start.sh`，选择「配置 Remotion 远程渲染」。
- 命令入口：`bash start.sh remote --project "/已有工程"`。
- 帮助：`bash start.sh script-help remote`。
- 等效独立配置：`bash remote/start-remotion-remote.sh --project "/已有工程" --configure`。

未指定工程时按提示选择已有工程目录。工具包只允许配置流程及项目路径参数，不提供前台运行、登录自启动、停止或卸载入口。

配置检查现有依赖与 Git 远端读取权限，收集输出目录、保留小时数及登录账号，确认后写入私有配置、带盐密码哈希和内嵌代码。不会创建 LaunchAgent plist，不会调用 launchctl bootstrap/kickstart/bootout，不会停止或杀死已有进程。已有运行实例、已加载服务或现存登录启动 plist 时拒绝覆盖；请先在工具包外自行处理旧服务。

## 独立运行能力不属于工具包配置

独立脚本保留旧工作流的 `--foreground`、`--install`、`--status`、`--stop` 和 `--uninstall`，供用户日后在工具包外显式使用。直接打开独立脚本也有独立菜单。配置完成不会触发这些动作；前台运行/安装命令仍会再次要求配置确认。

以下运行时行为仅在日后显式启动服务后发生。详细命令见 [Remote README](../remote/README.md)。

## 工程与环境要求

- macOS，已有 Node.js 24+、pnpm、Git，已有安装好依赖的 Remotion 工程，工作区干净。
- 当前 Git 分支有 upstream，能够非交互读取远端分支。配置时检查读取权限，不执行原地 `git pull`，不创建凭据、不猜测分支；detached HEAD 或无 upstream 则停止。
- 初始适配器只支持已经核对源代码的 `@remotion/cli` 4.0.518 / 4.0.534，不支持的版本关闭式拒绝，不自动升级或降级。版本通过检查不等于任何工程均已实机兼容。
- 选择已存在、已挂载、可写的独立输出目录。输出放入服务控制的任务子目录，而非任意浏览器提交路径；不会替你创建磁盘挂载点。

## 网络、确认与登录启动

公共入口为 `0.0.0.0:43871`，强制账号密码认证；内部 Studio 端口为 `127.0.0.1:43872`。配置询问输出目录、保留小时数、账号和密码，并明确确认后只保存配置。公共入口与内部端口此时只是配置值，不开放监听。浏览器访问 `http://Mac的私网地址:43871/`，状态与成品下载页面 `/_remote/`；`/_remote/status` 和 `/_remote/jobs` 是 JSON 接口。

绑定所有网卡不等于只允许私网访问。HTTP Basic 不加密，仅用于可信局域网或已经配置的私有 VPN；不要直接暴露到互联网。脚本不设置路由器、防火墙、TLS 或 VPN，认证不是公网安全保证。它会执行工程代码，因此只接入信任的仓库、分支及提交。

登录自启动使用当前用户的 LaunchAgent，无需 sudo，只有用户登录后才启动，并非无人登录即可运行的系统服务。停止菜单针对登录服务；前台进程按 Ctrl+C 停止。卸载登录服务保留配置、缓存与渲染输出。

## 更新与输出

每 60 秒检查远端 Git，有新提交时准备独立固定 SHA 的 worktree，确认渲染空闲后才切换；不是每分钟重启，也不是在正在运行的工程内 `pull`。状态不明或依赖清单/锁文件变化时保留当前版本并报告，不自动安装依赖。Git 元数据会更新，但主工作区文件不改动；独立 worktree 复用已有 node_modules，并非全新依赖安装。

成功输出可通过认证的输出页下载。下载结束不触发删除，默认不启用 TTL 清理；配置时可选择保留小时数，明确确认后仅清理本服务登记的已完成输出，下载中的文件跳过。未下载的成品也可能到期，请及时保存。历史版本缓存仍由用户管理。单独音频输出不在当前适配器范围内。磁盘缺失时不应创建同名空目录绕过检查。

仅完成静态及隔离模拟测试，不表示已在用户 Mac 部署或真实渲染验收。如果日后另行启用运行服务，请在工具包外前台检查登录、渲染、指定磁盘输出、下载，以及渲染繁忙时 Git 切换等待。独立模块的详细排障与安全说明见 [Remote README](../remote/README.md)。

失败或未知任务会阻止自动切换，请先排查并在维护窗口停止、重启服务。运行中不要手动改动所复用的 node_modules。
