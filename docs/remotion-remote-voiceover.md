# Remotion 远程渲染：约 30 秒口播

这套脚本，把 Mac 变成 Remotion 远程渲染工作站。先准备好能运行的项目，再填写本地仓库目录、视频输出目录、保留时间，以及登录用户名和密码。保留时间填零，就不自动删除。配置完成后，按提示另行启动服务。同一局域网里的电脑打开访问地址，登录就能预览、提交渲染，再从成品页面下载视频。

## 配套说明（不必逐字口播）

- 五项设置，密码需要重复输入，最后输入 YES 确认，共七次输入；不计工具包菜单选择。通过 `--project` 预先指定目录时少一次。
- 仓库位置指已克隆到 Mac 的本地目录，不是 GitHub URL。远端地址及分支从现有 Git upstream 读取，不自动 clone、不设置凭据。
- 需要 macOS、已启用的 Node.js 24+、pnpm、Git、已装依赖且支持的 Remotion 4.0.518 / 4.0.534 项目，以及已存在且可写的输出目录。
- 工具包入口只保存配置；不启动服务、不安装登录自启动。独立脚本的前台启动或安装登录服务是另一项显式操作，仍会经过配置及确认流程。不要把“配置完成”描述为“已上线”。
- 服务启动成功后访问 `http://Mac私网IP:43871/`；成品和状态页为 `http://Mac私网IP:43871/_remote/`。`0.0.0.0` 是监听范围，不是给另一台电脑使用的访问地址。
- 保留时间为正数时，服务登记的已完成输出到期会永久删除，即使未下载；正在下载的文件跳过，不清理其他文件。默认 0，不自动删除。
- HTTP Basic 不加密，只用于可信局域网或已配置的私有 VPN，不应把端口映射到公网。六位密码是最低允许长度，不代表推荐强度。
- 不改 Remotion 原项目配置和依赖；本次没有在用户 Mac 上安装或进行真实远程渲染验收。
