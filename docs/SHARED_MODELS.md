# 独立共享模型目录

程序和权重分开。交互下载时，共享根目录只问一次，默认 `~/AI/models`；也可选择自己已挂载的外置盘目录。显式传 `--models-dir` 后不再询问路径；旧参数 `--dest` 与它等价，不能同时传。不要把权重放进 `.app`、工具包或虚拟环境。

在工具包根目录的终端运行 `bash start.sh`，在菜单设置共享目录，再选择预览或下载。目录在本次菜单会话内沿用，不保存额外配置；进入菜单后无需再输入启动命令。

## 完整模型包

菜单只分 LLM、音频、图像/视频；选择模型即自动加入必需组件，不用手选编码器、VAE 或 tokenizer。在菜单查看模型技术详情，包括仓库与文件信息。

```text
~/AI/models/
  llm/
    Qwen3.8-Flash-Next-MLX-Serve-8bit/
    Qwen3.8-27B-bf16/
      mtp/                       # 原始 BF16 副头与兼容 weights.safetensors
  images/
    Qwen-Image-2.1/          # 原路径 diffusion_models、text_encoders、vae
    Krea-2/                  # 仓库原有 diffusion_models、text_encoders 等路径
      dependencies/Wan_2.1_ComfyUI_repackaged/
  music/
    MiniMax-Music3-MLX-Serve-8bit/
    Yue2-3B-GGUF/
  video/
    MiniMax-H3-FL2VA-MLX-Serve-8bit/
    MiniMax-H3-REF2VA-MLX-Serve-8bit/
  audio/
    Qwen3-ASR-1.7B-GGUF/   # Qwen3-ASR，不套 audio.cpp-gguf 外层
  Mac-AI-Manifests/         # 下载记录，不是应用配置
```

实际模型目录按 `llm`、`audio`、`music`、`images`、`video` 用途分类，保留原仓库名或仓库内模型包名及大小写，不额外套推理框架父目录。原名里的 `MLX-Serve`、`GGUF`、`ComfyUI` 不是额外父层，不删改。`dependencies`、`mtp`、`licenses` 是组件/用途子目录，仍保留；下载 ID 仍保持稳定，不等于目录名。

全部清单经审计后未再改目录，上述路径均符合规则。框架与权重仍需格式及架构兼容，去除目录绑定不代表任意框架都能加载任意 GGUF。

Qwen-Image-2.1-Turbo 配齐 BF16 主干、编码器及专属 RGBA VAE，约 32.44 GB。Krea2 只保留 Turbo，文本编码器与 VAE 自动配齐。各组件子目录内仍保留上游仓库文件路径，启动时应使用下载计划打印的实际文件路径，不把上述目录名当成权重文件名。

Music3 和 H3 的下载 ID 分别为 `music3-mlx-8bit` 与 `h3-mlx-8bit`，使用上述完整 MLX-Serve 8bit 包目录。H3 另有 REF2VA 可选项，支持音频等参考，见 [H3 说明](H3.md)。旧版 Music3/H3/YuE2 转换素材入口已删除，YuE2 改用现成 audio.cpp GGUF 完整套装，主模型 BF16、VAE F32，并自动配齐外置文件；ID 为 `yue2-audio-cpp-bf16`，目录为 `music/Yue2-3B-GGUF/`。新版不会自动搬迁、删除旧权重，也不会将原始素材冒充转换包复用。

音乐模型统一放 music 子目录，Qwen3-ASR 转写放 audio；菜单仍维持三组，音乐也在“音频”组选择。这只是新下载目录规则，不会自动迁移原来的 audio-cpp 或 audio/music3-mlx-8bit 文件。

## 应用只引用权重，不复制一套

- 菜单的共享路径仅在本次会话生效，下载器本身不修改应用偏好。以后仍选择同一个共享根即可。
- MLX-Serve 仅安装桌面 App，用户手动打开并添加本地模型目录、加载及开启 API；不配置 CLI。下载统一走本包菜单。
- MLX-Serve GUI 应设官方 Settings → Model Folders → Default folder。安装器只有显式传入 `--models-dir` 才配置它（菜单安装会传入本次选定的共享目录），而且目录必须已存在、可读写；详见 [安装说明](INSTALL.md)。Custom folder 仅增加扫描，不替代默认下载位置。
- 外置盘先挂载再启动 GUI。目录失联时上游可能回退内置位置，本工具无法禁止；下载前检查设置。GUI 删除模型会影响共享文件，勿随意删除。
- MLX-Serve 的模型扫描并非任意深度；`llm/<model>` 为两层布局。sd.cpp 的组件目录不要求由 GUI 当作 MLX 模型识别。
- llama.cpp、stable-diffusion.cpp、audio.cpp 使用各自支持的本地路径参数，指向正确文件和配套组件，不直接传整个共享根期待自动识别。
- llama-swap 保存服务启动命令和路径，不存储或转换权重；Hermes 调用 API，不另存一套。
- 文件扩展名相同不代表兼容。音频 GGUF、图像编码器 GGUF、语言模型 GGUF 不能互换；共享目录也不代表可以安全同时加载。

更换根目录不会搬迁旧文件或修改其他服务配置。先确认文件和下载记录，再在对应应用更新引用；工具不自动迁移、删除或重下全部模型；普通下载任一 H3 版本都会自动检查同一根目录中的另一版及旧默认 `video/h3-mlx-8bit`，只有 SHA256 一致的文件才建立链接；其他位置需显式提供，原文件必须保留。下载预览不创建目录、不保存设置；真实下载选好模型和目录即开始，不再追加确认。请预先检查磁盘空间，许可详见文档或 `--details`。

## 合并已下载的 H3 共享文件

在「管理本地模型 → 合并 H3 共享权重」中，自动检测当前模型根中的两版原始仓库目录及旧 `video/h3-mlx-8bit`，不询问来源或目标版本，也不下载缺少的模型。

仅对核查快照中两版相同的文件核验完整 SHA256 和字节数。保留一份真实文件，把另一份已确认相同的文件替换成相对符号链接；不同、损坏、缺失或不安全的文件不改。替换过程中使用同目录恢复备份。已有正确共享链接不会再次处理。

请勿与模型下载或修改文件同时运行。保留的源目录不能删除或搬走。汇总显示的是去重文件的逻辑大小，APFS 克隆、快照或稀疏文件会影响实际释放空间。

## 再次下载与补齐组件

选择模型后，先显示正在检查的模型根目录，核验已有文件，再打印“已有、需补、本次新增”。磁盘检查按本次缺失文件及必要暂存峰值，不再按整包大小拦截。完整文件直接跳过；例如已有 Qwen BF16 主模型时，只补一份最终 MTP；新下载原件适配后自动清理。全部齐全显示“无需重复下载”。

所有启用的清单模型均按固定文件大小与完整 SHA256 核验。除标准路径，还检查所选根目录下仓库名、模型 ID 和常见旧分类目录；不递归扫描其他磁盘。旧文件同盘且完全匹配时只读识别；不再自动硬链接组装、复制、搬迁或删除来源，需明确迁移或使用原目录。H3 保留既有的共享链接机制。跨磁盘旧文件不会自动硬链接，也不会不计空间地复制。

目标文件不符或链接不安全时明确报错，绝不覆盖。旧位置的同名不匹配文件保持原样，并提示未复用。已验证的受控暂存文件也会扣除；未验证的半成品保守预留完整文件空间，不承诺客户端下载续传的字节数。只读列表和预览不扫描大权重 SHA；真正下载前的完整校验可能需要一些时间。若未发现已有模型，先核对打印的根目录是否正是旧模型所在目录。

Qwen3-ASR 新下载位置为所选模型根目录下的 `audio/Qwen3-ASR-1.7B-GGUF/qwen3-asr-1.7b-f16.gguf`。上游仓库仍是 `HereIsMark/audio.cpp-gguf`；下载根设为 `audio`，保留上游文件的 `Qwen3-ASR-1.7B-GGUF/` 相对路径。旧版 `audio/audio.cpp-gguf/Qwen3-ASR-1.7B-GGUF/` 仍可只读识别；不自动硬链接、复制或移动旧文件；需明确迁移或使用原目录。API.md 使用实际识别到的文件路径。

此目录调整不更新 ASR 权重快照；上游 `master` 若已变化，原有大小/SHA256 校验仍可能拒绝下载结果，不能把目录修正当作下载或推理验收。
