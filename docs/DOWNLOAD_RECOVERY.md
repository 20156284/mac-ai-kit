# 下载与外置磁盘恢复

## 外置盘占位身份识别与只移动发布

下载到同盘自有暂存目录，完整大小与 SHA256 校验后移动到最终位置；已有完整文件跳过。不尝试硬链接，不为发布生成第二份模型，不跨盘复制。不采用“复制后独占重命名”的路径：某些文件系统可能不支持这一操作；相关用户报告与此路径相符，但没有真实 Mac traceback，不能断言磁盘格式或 `.gitattributes` 损坏。

独占重命名不支持时，使用本工具协作锁、独占创建的占位文件与精确随机标记复核后普通同盘移动。已发现的目标冲突不覆盖；普通移动降级不是系统级原子 no-clobber，最后检查与移动之间不能阻止外部写入，运行时请关闭其他会修改模型目录的下载器。留下的空 `.publish-lock` 是微小协作锁，不是权重副本。

占位认领不依赖文件描述符与路径查询的 dev/ino 相等：某些文件系统可能返回不稳定的标识，不能仅凭不相等就断言被其他程序修改。认领条件是精确来源路径、合法随机标记、普通文件类型和完整标记内容一致；不推断用户磁盘格式。

中断后已发布文件校验跳过，未发布 stage 保留；带完整日志的自有占位可恢复，包括旧日志中记录 dev/ino 不一致的情况。继续从同一模型根、同一选择重试，无需先删除占位或暂存文件。有效 stage 原件与适配临时文件会重新校验复用，不重新联网下载，也不重新生成已有完整临时文件。未知或内容不符的占位、错误来源路径、链接、坏临时文件不会覆盖。若在占位创建与记录写入之间崩溃，未知占位不会自动删除，需要检查后处理。早期目标旁精确 `.文件名.32位十六进制.publish` 临时文件仅在完整 SHA256 匹配时可移动复用，成功后清理精确归属的 stage；其他旧副本与未知文件不擅自删除。旧用户目录文件只读识别，不自动迁移、硬链接或复制，须明确迁移或使用原目录。

目录组件首尾空白曾导致 `models` 和 `models ` 成为两个不同目录，Finder 中可能看起来一样。工具包自动清理模型目录输入整体首尾的普通空格、Tab、NBSP 等 Unicode 空白，再校验路径内部组件；允许 `My Models` 这样的内部空格，字面反斜杠也不会删除。交互时全空白使用默认目录；显式 CLI 目录为空白则拒绝。路径中间组件边缘的空白仍须显式重新选择。不会自动重命名、迁移、合并或删除旧文件；重新选择根目录时会复用已存在的 `models`，不额外创建 `models/models`。

若原件在带尾空格的旧根中，指定准确旧 `mtp` 路径即可只读复用（注意引号内 `models` 后的空格）：

```bash
bash start.sh download --models-dir "/Volumes/Samsung1TB/AI/models" \
  --select qwen38-27b-bf16 \
  --reuse-mtp-source "/Volumes/Samsung1TB/AI/models /llm/Qwen3.8-27B-bf16/mtp"
```

只核验旧 `mtp/model.safetensors` 或它旁边具有精确所有权标记的暂存原件。旧目录保持原样；若原件缺失/校验失败，计划会明确显示仍需下载。H3 跨版本去重仍需要符号链接支持；不支持时明确停止，不以复制冒充节省空间。普通模型发布不再使用复制降级。尚未在用户 Mac 或移动硬盘上验证。
